# Dunder Mifflin × Headless Fleet — project conventions

This is **Next.js 16** (App Router, React 19.2, Tailwind v4, Turbopack default). A polished, on-brand
**Dunder Mifflin Paper Co. "Agent Fleet"** UI that demos the LangChain Fleet API. No DB — the Fleet API is the backend.

## Next.js 16 rules (DIFFERENT from older Next — follow exactly)
- **`params`/`searchParams` are Promises.** `await` them.
  - Pages: `export default async function Page(props: PageProps<'/agents/[id]'>) { const { id } = await props.params }`
  - Layouts: `LayoutProps<'/agents'>`. Route handlers: `async function GET(req: NextRequest, ctx: RouteContext<'/api/...'>) { const p = await ctx.params }`.
  - These `PageProps`/`LayoutProps`/`RouteContext` generics are GLOBAL (generated by `next typegen`). Use them.
- `cookies()`, `headers()`, `draftMode()` are async — `await` them.
- Tailwind v4: config is CSS-based in `app/globals.css` (`@theme inline { … }`). **There is no `tailwind.config.js`.** Brand color tokens already defined: `paper, paper-2, card, ink, ink-soft, ink-faint, navy, navy-600, navy-400, line, line-strong, accent, accent-soft, good/good-soft, warn/warn-soft, bad/bad-soft`. Use them as `bg-navy`, `text-ink`, `border-line`, etc.
- Don't read `process.env` for secrets in client components. Secrets live ONLY in `lib/fleet/server.ts` (server). `NEXT_PUBLIC_` only for non-secret values.

## The Fleet client contract (import these — do NOT re-implement fetch/auth)
- **Browser code** calls our own proxy via the typed helpers in `@/lib/fleet/endpoints`:
  `Agents`, `Threads`, `Models`, `Secrets`, `Auth`, `Integrations`, `Skills`, `Tenants`, `Users`.
  e.g. `const { items } = await Agents.list({ name, include: ["owner"] })`.
  Low-level: `api<T>(path, {method, query, body})` and `streamRun()/parseSSE()` from `@/lib/fleet/client`.
- **Types** live in `@/lib/fleet/types` (`Agent`, `Thread`, `FleetModel`, `ProviderResponse`, …).
- Errors thrown are `FleetClientError` with `.status`, `.code`, `.detail`. Catch and surface `.detail`.
- The API key + `X-Tenant-Id` are injected server-side by `app/api/fleet/[...path]/route.ts`. **Never** put a key in client code or call `api.smith.langchain.com` directly from the browser.
- Live workspace already has 21 agents, 18 models, real secrets/skills/providers. `GET /users/current` 403s — treat identity as optional.
- Prefix anything you CREATE in the live workspace with `"DM Demo — "` so it's easy to spot/clean up.

## Design system (import — do NOT rebuild)
- Everything is re-exported from the barrel `@/components/ui`: `Button`, `Card`/`CardHeader`/`CardTitle`/`CardBody`, `Badge`, `Input`, `Textarea`, `Select`, `Label`, `Field`, `Spinner`, `Skeleton`, `Tabs`, `EmptyState`, `cn`, `Dialog`, `ConfirmDialog`, `useToast`, `ToastProvider`, `Table`, `THead`, `TR`, `TH`, `TD`. (Subpath imports like `@/components/ui/Toast` also work.) No `IconBadge` — use `Badge` or `AgentIconTile`.
- Brand shell in `@/components/brand`: `AppShell` (sidebar + topbar, already wired into routes), `DunderMifflinLogo`.
- Icons: `lucide-react`. Agent `display.icon` strings are free-form (e.g. "Bell03") — map best-effort, fall back to a default icon.
- Tone: corporate-but-warm, restrained "The Office" flavor in empty states/copy. Polished, accessible, with loading skeletons and toasts. Avoid generic AI-template aesthetics.

- After adding routes, regenerate types: `npx next typegen`.
